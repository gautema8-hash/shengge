# admin/frontend — 「生格」管理后台（Web 实现版）

与 `../ui/后台原型-低保真-v1.html` **1:1 还原**，7 个页面全部接真实 API：

数据看板（匿名聚合 KPI + 7 日柱状图 + 情绪分布）｜ 轻提问题库（增/编辑/复审/下架）｜
热线配置核验（替换、至少保留 1 条有效）｜ 敏感词库（分级新增、复核、同步端侧）｜
风控事件（脱敏）｜ 操作审计日志 ｜ 用户管理（匿名视图）。

## 运行

```bash
# 方式一（推荐）：由管理 API 托管
cd ../backend && node server.js   # http://127.0.0.1:8102/

# 方式二：直接双击 index.html（离线演示模式，展示与原型一致的假数据）
```

- 技术栈：原生 HTML/CSS/JS，零构建；设计 Token 与 App 同源（DesignSystem §10 后台差异点：页面底 #F5F5F4、信息密度提高、5 色数据可视化色板）
- 写操作全部自动记入审计日志；任何页面不存在"查看用户日记"入口
