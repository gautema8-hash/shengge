# app/frontend — 「生格」App 高保真实现（Web 版）

与 `../ui/App原型-低保真-v1.html` **1:1 还原**的可交互实现，覆盖原型全部 16 屏：

| 屏 | 内容 | 交互 |
|----|------|------|
| 屏1 | 首启欢迎页 | 首次进入展示；「开始 / 先随便看看」 |
| 屏2 | 生命方格（主页） | 倒计时/收集双视角切换、进度条、格子可点击 |
| 屏3 | 记录 Tab | 今日轻提问（后端下发）、情绪三通道标注、保存 |
| 屏4 | 愿望 Tab | 清单勾选完成、新增 BottomSheet |
| 屏5 | 危机干预弹窗 | 白底黑字缓入、拨打 12356（热线来自后端配置） |
| 屏6 | 我的 Tab | 偏好/数据/关于分组 |
| 屏7 | 方格详情＋补记 | 点格子进入，补记 BottomSheet |
| 屏8 | 日记详情＋删除 | 二次确认弹窗 |
| 屏9 | 新增愿望 | BottomSheet |
| 屏10 | 悄悄放弃 | 无指责确认文案 |
| 屏11 | 默认视角选择 | BottomSheet 单选 |
| 屏12 | 生日与预期寿命 | 日期选择 + 60~100 拖动滑杆 |
| 屏13 | 云同步订阅页 | 调用 `/api/v1/auth/guest` 生成匿名账号 |
| 屏14 | 导出 | JSON 备份真实可下载、年度格子海报真实生成 PNG |
| 屏15 | 产品宪法 | 六条"永不" |
| 屏16 | 意义快照 | 解锁进度（30 天/份，不清零） |

## 运行

```bash
# 方式一（推荐）：由薄后端托管，配置下发/审核兜底生效
cd ../backend && node server.js   # http://127.0.0.1:8101/

# 方式二：直接双击 index.html（离线模式，内置降级数据，全部功能可用）
```

- 技术栈：原生 HTML/CSS/JS，零构建、零依赖；色彩/字号/间距 Token 与《生格-设计规范-DesignSystem.md》v1.0 完全一致
- 数据：本地优先（localStorage 权威源）；后端在线时自动拉取题库/热线、保存时走审核兜底
- 危机干预：命中 L2 词 → 白底黑字危机弹窗 + `tel:` 拨打热线（后端与端侧双层引擎）
- 说明：本实现作为 Flutter 工程（W1）的**高保真视觉与交互基准**； Flutter 骨架按 DesignSystem §9 映射落地时逐屏对照
