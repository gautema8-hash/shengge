# person_dev 项目工作区

「生格」App + 管理系统的统一工作区。**所有新代码与文档必须放入对应文件夹，禁止在根目录散放。**

## 目录结构与存放规则

```
person_dev/
├── app/                    # 「生格」App（用户端产品）
│   ├── frontend/           #   前端：Flutter 工程（iOS + Android）
│   ├── backend/            #   后端：薄后端 Node.js(NestJS) + MySQL + Redis
│   └── ui/                 #   UI：设计规范、设计 Token、图标、切图说明
├── admin/                  # 管理系统（运营后台，阶段5启动）
│   ├── frontend/           #   前端：React / Vue（规划中）
│   ├── backend/            #   后端：管理 API（规划中）
│   └── ui/                 #   UI：后台设计（沿用 App 设计 Token）
└── docs/                   # 全部项目文档（唯一文档存放处）
```

## 放置规则（硬约束）

| 产出物 | 放入位置 |
|--------|---------|
| Flutter 代码 / 组件 / 测试 | `app/frontend/` |
| 后端代码 / SQL / 部署脚本 | `app/backend/` |
| 设计规范 / 色板 / 图标 / 设计稿说明 | `app/ui/` |
| 管理系统各类产出 | `admin/` 对应子目录 |
| 需求 / 战略 / 合规 / 计划 / 会议纪要等 md 文档 | `docs/` |
| 临时草稿、实验性代码 | 各子目录内建 `scratch/`，不进版本库 |

## 命名规范

- 文档：`主题-名称.md`（如 `生格-技术文档.md`）
- 代码文件：小驼峰 / 下划线随框架惯例；组件文件 PascalCase
- 不使用中文路径创建代码文件（Windows 编码风险）；文档可用中文
