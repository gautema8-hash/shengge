## 1. 安全加固清单（已内置）

### 防黑客（服务端）

| 措施 | 实现 | 位置 |
|------|------|------|
| 登录鉴权 | Bearer 会话令牌（随机 24 字节，8h 过期），除 login/health 外全部管理 API 强制 | guard.js `issueToken/verifyToken` |
| 防爆破 | 登录失败 10 次/5 分钟/IP → 429 锁定，且写入审计日志 | admin server login |
| 全局限流 | App 240 次/分/IP；审核 60 次/分/IP；后台 120 次/分/IP（env 可调） | guard.js `rateLimit` 滑动窗口 |
| 请求体防护 | 上限（App 512KB / 后台 256KB）+ 畸形 JSON 400，超限不断连可回 413 | guard.js `readBody` |
| 输入校验 | 全字段类型/长度白名单化（`str/intOf`），状态值枚举校验 | 两个 server.js |
| 错误脱敏 | 内部异常只进服务端日志，对外统一"服务暂时不可用" | 两个 server.js catch |
| 安全响应头 | nosniff / DENY 嵌入 / no-referrer / Permissions-Policy | guard.js |
| CSP | HTML 响应强制 CSP + frame-ancestors 'none' | guard.js `applyCSP` |
| 路径穿越 | `\0`/`..` 拒绝 + normalize 前缀比对（已适配 Windows/POSIX 分隔符） | guard.js `serveStatic` |
| 缓存策略 | API 一律 no-store；静态 1h；HTML no-cache | guard.js |
| CORS | 默认同源放开；生产 `SG_CORS_ORIGIN=https://你的域名` 收紧 | guard.js |
| slowloris | headersTimeout 35s / requestTimeout 30s / maxHeadersCount 64 | 两个 server.js |
| 后台禁索引 | robots.txt Disallow: / | admin server |

### 防逆向（纵深防御）

1. **前端无秘钥无敏感逻辑**（架构级）：日记本地存储 / 云同步 E2E 加密、服务端只存密文——拿到前端代码也拿不到用户数据
2. **发布构建**：`node tools/build-dist.js` 产出 `dist/`（剥注释/压缩/去 console），生产用 `SG_FRONTEND_DIR=.../dist` 加载，与源码解耦
3. **敏感词 patterns 永不出 API**（词库接口只回脱敏 masked）
4. **审核接口不存原文、不回显**（仅返回 level/action）
5. **原生壳层（Flutter 正式版）**：`flutter build apk --obfuscate --split-debug-info=...`、iOS 符号剥离；上架前建议商业加固（360加固/腾讯乐固）
6. robots + 静态目录不可列举

## 3. 生产部署清单（Go-Live）

```bash
# 1. 改默认管理员密码（必须！）
export SG_ADMIN_USER=你的账号 SG_ADMIN_PASS=强密码
# 2. 收紧 CORS
export SG_CORS_ORIGIN=https://app.yourdomain.com
# 3. 加载 dist 构建（防逆向）
export SG_FRONTEND_DIR=/opt/shengge/app/frontend/dist
# 4. 启动（建议 pm2 守护）
pm2 start app/backend/server.js --name shengge-app
pm2 start admin/backend/server.js --name shengge-admin
```

- **必须 HTTPS**（Nginx/Caddy 反代 + TLS1.2+），令牌与日记元数据才受传输层保护
- 限流当前为单机内存版；**多实例部署时切换 Redis 令牌桶**（guard.rateLimit 接口不变）
- 会话为内存版；多实例时换 JWT 或集中式 session（Redis）
- 数据库：按《生格-技术文档》§4.2 切 MySQL 8.0（本机已装）+ Redis 5.0
- 备份：server-data/db.json 定时快照；风控/审计日志 ≥6 个月留存（合规）
- 监控：`/ping`（App）、`/api/admin/health`（后台）接入探活；关注 429 与 5xx 比率

## 4. 已知边界（诚实声明）

- JSON 文件存储为单机方案，商用上量后切 MySQL/Redis（schema 已在技术文档中定义）
- 会话/限流为单实例内存版，横向扩容前需集中化
- 前端 CSP 保留 `unsafe-inline`（内联事件绑定），切 React/Vue 构建后可移除
- 登录无验证码（限流已兜底）；公网暴露前建议加图形验证码或 OTP
