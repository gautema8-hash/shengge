# 「生格」文案库 v1

## 1. 首启引导页（仅首次）

- 标题：欢迎来到生格
- 主文案：
  > 很多人终其一生，都没有找到所谓的人生意义。
  > 暂时迷茫，不是你的失败。
  > 这里不给你答案，只陪你把每一天过成可以回看的样子。
- 副文案：同一份生命格子，可以看成倒计时，也可以看成收集。
- 按钮：`开始`（Primary）/ `先随便看看`（Ghost，游客模式直入）
- 页脚 Footnote：使用即表示同意《用户协议》与《隐私政策》。本工具仅用于自我记录，不能替代专业心理帮助。

## 2. 入门三问（可全部跳过，不打分）

- 页面标题：三个松弛的问题（可跳过）
- Q1：最近，有没有哪个瞬间让你觉得"还不错"？（哪怕很小）
- Q2：哪些事情做完，会让你觉得被消耗？
- Q3：如果不用考虑收入，也不用在意别人的眼光，你想试试什么？
- 按钮：`写好了`（保存并进入）/ `跳过`（Text）
- 结束页文案：没有标准答案。以后随时可以在"我的"里修改。

## 3. 每日轻提问（30 条，随机不重复近 7 天）

### 感知当下（8 条）
1. 今天哪一刻，你觉得活着还不错？
2. 现在窗外的天色是什么样的？
3. 今天有没有哪个声音，让你停了一下？
4. 今天的身体感觉怎么样，哪里松，哪里紧？
5. 今天你注意到什么平时会忽略的小东西？
6. 此刻安静下来，你脑海里浮现的第一个画面是什么？
7. 今天摸到的最舒服的东西是什么？
8. 今天的空气闻起来是什么味道的？

### 回忆与意义（7 条）
9. 如果今天可以重来，你想改变哪一件小事？
10. 小时候的你，会喜欢今天的你做的哪件事？
11. 最近有没有一瞬间，你觉得"这就是我想要的生活"？
12. 你上一次大笑是什么时候，因为什么？
13. 有没有一个地方，你想到就会安静下来？
14. 谁说过的一句话，你记到现在？
15. 最近哪件小事，做完之后你心里很踏实？

### 消耗与滋养（7 条）
16. 最近什么事在消耗你？
17. 最近什么事在滋养你？
18. 今天有没有对谁说"不"，感觉怎么样？
19. 今天哪件事让你觉得"不值得"，下次可以怎么放过自己？
20. 有没有一件小事，你一直想做却一直拖着，它卡在哪一步？
21. 今天你为自己做了什么？
22. 如果把今天的疲惫画成天气，是什么天气？

### 想象与微小行动（8 条）
23. 如果没有任何人评价你，你想做什么？
24. 这辈子想体验的一件小事是什么？
25. 如果明天只有半天属于自己，你想怎么过？
26. 有没有一个角落，你想坐一会儿？
27. 想给很久没联系的人写一句话吗？写写看。
28. 如果给一年后的自己留一句话，你会说什么？
29. 今天有什么东西，值得拍下来留给以后看？
30. 最近有没有想学的"没用但想学"的东西？

> 使用规则：每天随机 1 条；用户可切换成自写问题；**不设"漏答提醒"**。

## 4. 空状态文案（10 条，全部不催促）

| 场景 | 文案 |
|------|------|
| 方格未记录 | 第一格还空着。什么时候想涂，都可以。 |
| 日记为空 | 这里很安静。想写的时候，它一直在。 |
| 愿望为空 | 有没有一件小事，是你想体验的？想到再说。 |
| 愿望全部完成 | 都完成了。慢慢攒下一批也不急。 |
| 实验为空（迭代期） | 这里会有一些 10 分钟的小尝试。看到合眼缘的再说。 |
| 线索数据不足 | 记录还太少，看不出线索。攒一段时间再看。 |
| 搜索无结果 | 没找到。也许那天你什么都没写，这也很好。 |
| 断网 | 网络不在也没关系，记录都在你手机里。 |
| 同步关闭 | 你的记录只存在这台手机里。想多一份安心时，可以打开同步。 |
| 首条记录完成 | 今天的格子，涂上了。 |

## 5. 按钮 / 微文案原则

- 确认类：`保存`、`写好了`、`完成`（不用"立即提交""马上记录"）
- 跳过类：`跳过`、`先不用`、`下次再说`（永远给退路）
- 删除确认：标题`删除这条记录`；正文`删掉就找不回来了。确定吗`；按钮`确定删除`（Danger-ghost）/ `再想想`
- 禁止：感叹号、倒计时文案、`你还有 X 天`式恐吓、任何"赶紧"类字眼
