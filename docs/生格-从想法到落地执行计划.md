# 「生格」从想法到落地 · 全程执行计划

> 目标：把「生命感知 + 微小人生探索工具」从一个想法，推进到合法上架、可运营的 App 产品。
> 定位锚点：Flutter 双端 App 主体 ｜ 本地优先架构 ｜ 微信小程序仅作海报工厂
> 生成日期：2026-10-15 ｜ 环境：已就绪（见《开发前环境准备文档.md》终检通过）
> 关联文档：《生格-技术文档.md》v2.0、《生格-App战略分析报告.md》、《生格-合规与标准化建设方案.md》

## 一、全景路线图（一页看懂）

```
阶段0 立项与决策 ✅已完成
   └→ 阶段1 合规与主体准备（第1~8周，与开发并行）
         └→ 阶段2 产品设计定稿（第1~3周）
               └→ 阶段3 App MVP 开发（第3~10周）★当前阶段
                     └→ 阶段4 测试与上架（第8~12周）
                           └→ 阶段5 增长与商业化（第12周起，持续）
```

核心原则：**合规先行（资质周期最长最先动）、开发并行、每周有可运行产物。**

## 三、阶段1 · 合规与主体准备（第 1~8 周，最优先启动）

> 为什么最先：公司注册→软著→备案是全链路周期最长的环节（约 2 个月），卡住它们就卡住上架。

| # | 任务 | 责任 | 预计耗时 | 交付物 |
|---|------|------|---------|--------|
| 1.1 | 注册有限责任公司（经营范围含"软件开发、技术服务"，**不含**医疗/心理咨询） | 你 | 1~2 周 | 营业执照 |
| 1.2 | 开通对公账户、税务登记 | 你 | 1 周（可与1.1并行） | 开户许可 |
| 1.3 | 确定 App 名称「生格」（备选：时匣/度日集/余岁手记）并做商标近似查询 | 你+AI | 3 天 | 商标申请材料 |
| 1.4 | 提交商标注册（第9类软件/第42类SaaS/第16类印刷品） | 你 | 提交 1 天，下证 8~12 月 | 受理通知书（上架够用） |
| 1.5 | 申请软件著作权（App 客户端） | AI 代写代码文档材料 | 1~2 月（可加急） | 软著证书 |
| 1.6 | 购买域名 + 服务器（轻量云即可）+ ICP 备案 | 你 | 2~4 周 | 备案号 |
| 1.7 | App 备案（关联 ICP 备案，工信部平台） | 你 | 2~4 周 | App 备案号 |
| 1.8 | 起草《隐私政策》《用户协议》《免责声明》（按合规方案 §2 清单） | AI 起草+律师审阅 | 1 周 | 三份法务文本 |
| 1.9 | 咨询属地通管局：云同步收费是否需增值电信许可 | 你 | 3 天 | 口径结论 |
| 1.10 | PIA 个人信息保护影响评估报告存档 | AI 起草 | 3 天 | PIA 报告 |

**验收门 G1**：营业执照 + 软著受理 + 备案进行中 + 法务文本定稿。

## 五、阶段3 · App MVP 开发（第 3~10 周）★ 当前阶段

### 周计划（每周五交付一个可运行版本）

| 周 | 开发内容 | 技术要点 |
|----|---------|---------|
| W1 | 工程骨架：flutter create、目录结构、drift 表、主题 Token、Git 仓库 | 核心库选型落定（drift/riverpod/共享偏好） |
| W2 | 生命方格看板 v1：周格渲染、双模式着色、日期↔坐标纯函数+单测 | CustomPainter + RepaintBoundary |
| W3 | 方格 v2：点按格子补记、标签编辑、人生四季进度条 | 手势交互 |
| W4 | 轻提问日记：今日提问、日记列表、归档方格、端侧敏感词引擎 | 端侧词库 + 本地计数 |
| W5 | 愿望仓库 + 危机弹窗（12356 拨打）+ 免责声明页 | url_launcher 拨号 |
| W6 | 锁屏/桌面小组件：iOS WidgetKit 桥接 + Android Glance | App Group 共享数据 |
| W7 | 设置页：本地导出（JSON/PDF）、注销、关于页（产品宪法） | PDF 生成 |
| W8 | 云同步 v1（订阅预埋）：匿名账号、E2E 加密 blob、SyncQueue | 薄后端上线（MySQL/Redis 已就绪） |
| W9 | 性能与打磨：启动 <1s、方格滚动 60fps、断网全功能回归 | 离线队列压测 |
| W10 | 内测包：Android APK + iOS TestFlight，20 人种子内测 | 埋点（隐私合规版） |

### 并行任务
- **W6 起**：微信海报小程序开发（独立工程，仅海报生成，2 成精力）
- **W8 起**：商店素材制作（图标/截图/描述文案过广告法自查）

**验收门 G3**：内测 20 人 × 2 周；核心指标「30 天记录 ≥10 天用户占比」≥30%；崩溃率 <0.5%；断网全功能可用。

## 六、阶段4 · 测试与上架（第 8~12 周）

| # | 任务 | 要点 |
|---|------|------|
| 4.1 | 测试矩阵 | 功能/兼容（Android 8~15 + iOS 15+）/弱网/断网/权限拒绝/ 危机 SOP 全链路回归 |
| 4.2 | 安全与合规测试 | 隐私清单核对（工信部 164 号文格式）、敏感权限扫描、卸载残留 |
| 4.3 | 真机验收 | 小米 15（USB 调试 + QtScrcpy 投屏演示）、iPhone（借测或 TestFlight） |
| 4.4 | 上架材料 | 五大 Android 商店（华为/小米/OPPO/vivo/应用宝）+ App Store；类目"生活"，描述过文案黑白名单 |
| 4.5 | 灰度策略 | Android 分商店灰度 → iOS 全量；首周只收反馈不做推广 |
| 4.6 | 应急预案 | 商店拒审申诉模板；版本回滚流程 |

**验收门 G4**：双端过审上架，线上崩溃率 <0.3%，首周商店评分 ≥4.5。

## 七、阶段5 · 增长与商业化（第 12 周起）

| 时间 | 动作 | 指标 |
|------|------|------|
| 第 12~16 周 | 小红书冷启动：30 篇方格图文（AI 生成素材+真人使用叙事） | 海报→下载转化 ≥3% |
| 第 16~20 周 | 云同步订阅上线（68 元/年级别）+ 导出 PDF 付费 | 付费率 ≥2% |
| 第 20~24 周 | 年度格子海报实体版（跨年节点）；家庭篇功能立项 | 实体转化 ≥1% |
| 半年后 | 评估出海（memento mori 英语市场）与生命教育工具包 | 决策门：次月留存与口碑 |

**北极星指标不变**：30 天内有记录天数 ≥10 天的用户占比。**DAU 不是目标，"平静离开"才是。**

## 八、你下一步立即要做的事（本周清单）

1. **接真机**：小米 15 开 USB 调试连电脑，跑 `adb devices` + QtScrcpy 投屏（10 分钟，我可以现场指导）；
2. **确定产品名**：「生格」还是备选？定了才能交商标查询（1 天）；
3. **启动公司注册**：名称核准 + 经营范围确认（找代办最快 1 周下照）；
4. **买域名**：推荐 `.cn` 或 `.com`（如 shengge.app / shengge.cn），提交 ICP 备案；
5. **拍板原型**：让 AI 出阶段2的流程图+原型稿，你逐页确认——**这是动手写代码前唯一需要你决策的事**。

> 其中 1、5 今晚就可以做；2、3、4 决定了第 8 周后能否按时上架，越早越好。
