## 六、风险与备注

| 风险 | 说明 | 缓解 |
|------|------|------|
| JDK 全局切到 17 后老项目受影响 | 依赖 JDK 8 的老项目（如 Maven/Gradle 项目）编译可能报错 | 项目内 `org.gradle.java.home` 或 Maven toolchains 单独指回 jdk8；发现一个改一个 |
| Windows 版 Redis 5.0 已停更 | 官方早已不维护 Windows 分支 | 开发期够用；生产用 Linux/云托管 |
| 国内网络拉包慢 | Flutter/pub/Gradle 依赖拉取 | 已配置 flutter-io.cn 镜像；Gradle 走阿里云仓库（后端项目 build.gradle 内配置） |
| PATH 中旧 node_global 干扰 | 全局包可能装到系统 Node 侧 | 项目内一律本地安装，不用 -g |
| 多版本并存误用 | 终端里 python/node 可能命中不同版本 | 文档 §2.3 已列明采用版本；关键脚本用绝对路径调用 |
